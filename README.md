# Rideshare 99

A ride the driver keeps. This repo is the public wall. A pull request is a brick.

Anyone can add one. Use Cursor, Claude, ChatGPT, Codex, or any other agent, on your own account. Open a pull request. A GitHub username is enough. Use GitHub's private noreply email if you want your email off the commit.

Read [AGENTS.md](AGENTS.md), then pick an open issue.

The fare rule: the driver keeps the fare. One cent of each dollar keeps the infrastructure running. An outside owner gets 0. `node --test` fails if an outside owner takes a cut.

This does not pay anyone. No ride is a live service yet.
